[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on make.fun.

## The haiku

> One red breakpoint blinks
> the log line scrolls past midnight
> dawn finds the typo

Three lines, 5-7-5 syllables, 81 characters.

## Run

```sh
python3 main.py
```

It writes the haiku to `/output/entry.txt`.
